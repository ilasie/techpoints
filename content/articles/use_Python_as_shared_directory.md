> **WARNING**
> 
> 原则上，本文叙述的方案要求参与的主机连接同一内网，且务必确认该网络的安全性。

在Unix-like系统中，可以使用
```bash
python3 -m http.server [PORT]
```
在当前目录创建一个以`[PORT]`为端口的http服务器，这将会暴露当前目录下的文件作为网页内容。如果发现命令报错，你可能需要以任一形式安装Python 3.*。

现在你可以通过`wget`或`curl`抓取服务器主机的文件，这需要知道服务器IP。

以`wget`为例，抓取文件的命令是：
```bash
wget http://[IP]:[PORT]/[FILENAME]
```
这将下载服务器中对应的文件到当前目录。完成下载后，不要忘记使用`Ctrl+C`关闭服务器

在虚拟机上，假设宿主机IP为`192.168.122.95`，在虚拟机上可访问的服务器地址通常为`192.168.122.1`。
